📋 Project Overview & Architecture

The Rain Water Sensor & Real-Time Alarm System is an automated embedded hardware solution engineered to detect precipitation events with zero human supervision. The hardware combines a nickel-coated rain board sensor plate with an onboard LM393 comparator module connected to an Arduino Uno microcontroller.

⚙️ Key Engineering Features

  • Dual Output Acquisition: Leverages both Analog A0 (for measuring continuous precipitation intensity) and Digital D0 (for binary wet/dry threshold interrupts).
  • Dynamic Acoustic Warning: Activates a 5V piezo transducer with frequency modulation based on moisture saturation levels.
  • Visual State Indicator: Tri-color LED signaling (Green for Dry, Blue for Moisture Detected, Red for Heavy Rain Warning).
  • Anti-Corrosion Duty Cycling: Embedded C firmware duty-cycles the sensor plate power to prevent electrolytic degradation over prolonged outdoor operation.

🛠️ Technologies & Components

  • Embedded C
